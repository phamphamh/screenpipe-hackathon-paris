# Pitch DeloAI prêt : slides + démo en direct avec de vrais agents Claude dans Magento
- **Fait** : les slides du pitch, en anglais et en clair (`labs/phamphamh/agents-nova/slides.html`, publiées en artefact privé) ; la démo à part (`python3 labs/phamphamh/agents-nova/serveur.py` → http://localhost:8798) en 2 écrans façon SaaS : Audit (5 chiffres clés, détails au clic) et Office (bureau 3D : clic sur un salarié → ses workflows trouvés par l'audit → Deploy → Run it live) ; de vrais agents Claude traitent de vraies demandes WONDERBREAD dans la boutique Magento de WebArena (`boutique.py`, `agents_ia.py`), en direct dans une fenêtre de navigateur visible ; le script anglais (`script.md`).
- **Preuve** : passages réussis en visible pour Sophie (rapport des meilleures ventes 2022, commandes annulées) et Karim (rapport de février 2023 : 7 commandes, $749.00) ; changements de prix réels vérifiés sur la fiche produit ; parcours Audit → « See who does it most → Karim » → Deploy → Run it live cliqué dans Chrome.
- **Pas vérifié** : le changement de prix au ralenti en direct (peut être long avec 4 variantes) ; l'animation d'ouverture des détails de l'audit à l'œil nu ; autre Mac que celui de phamphamh.
- **Pour les autres** : la boutique de test (`labs/phamphamh/boutique/`) et l'outil `boutique.py` (chercher, prix, commandes, rapport) marchent pour n'importe quel agent ; les prix modifiés se remettent avec `python3 labs/phamphamh/agents-nova/boutique.py restaurer-prix`.
